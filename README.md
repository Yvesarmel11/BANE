# Multicorner

Application web (PWA) d'analyse de corners et de tirs : Multicorner (1MT × 2MT), Tirs (1MT + 2MT) et méthode Normale (Pour / Contre).

## Utilisation
Ouvrir `index.html` dans un navigateur, ou publier le dépôt avec GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `(root)`).

## Fichiers
- `index.html` : l'application
- `manifest.webmanifest` : installation sur l'écran d'accueil
- `sw.js` : service worker (fonctionnement hors ligne)
- `icon-192.png`, `icon-512.png` : icônes
